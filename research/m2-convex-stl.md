# M2 convex STL prototype

This first M2 slice implements ASCII and binary STL import, patch naming, convex surface validation, and volume meshing for [GEO-02 and the M2 benchmark](../docs/requirements.md). Both input variants describe oriented triangles. Binary detection uses the exact length implied by the little-endian facet count, including the case where a binary header begins with `solid`. ASCII names come from the solid declarations. Binary patch labels come from an optional facet-index mapping. [Library of Congress ASCII STL description](https://loc.gov/preservation/digital/formats/fdd/fdd000506.shtml), [UK National Archives binary STL description](https://www.nationalarchives.gov.uk/pronom/fmt/865)

The original Rust [surface validator](../crates/mesh-geometry/src/lib.rs) indexes equal coordinates, checks triangle validity, pairs each edge with one opposite use, and requires a single connected shell with positive volume. It checks all vertices against each outward supporting plane and uses planar projections to reject overlapping coplanar triangles. These checks apply in coordinates scaled by the longest bounding-box extent. The initial reference algorithm uses a plane tolerance of `8192 × f64::EPSILON` in those coordinates.

The [convex surface clipper](../crates/mesh-algorithms/src/voronoi.rs) starts from this validated shell and reuses the CPU site-bisector clipping loop and global face reconciliation. Each boundary fragment keeps its source triangle ID and named patch ID. The [mesh validator](../crates/mesh-quality/src/lib.rs) checks each fragment against its original triangle and checks per-facet area conservation as well as full domain-volume conservation. For the box benchmark this establishes geometric equivalence to the analytic box even when the STL triangles split a planar boundary face.

The [unit and skewed fixtures](../test-fixtures/) exercise orthogonal and angled boundaries. The skewed case has a unit-volume shear of the unit box, so a successful result distinguishes clipping at the angled shell from clipping at its bounding box. The [workflow tests](../tests/stl_workflow.rs) include malformed, inward, nonconvex, and non-manifold surface cases. The M2 scope also includes basic mesh size control as a subsequent step.
