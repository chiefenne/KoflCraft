# Tools

Generated by `kofl commands --markdown` from the tool registry (AG-12, crate `mesh-tools`); do not edit by hand. Every engine operation is a tool with a stable id, a contract version, a JSON input and output and an action kind: `read` reads and computes, `write-files` writes new files, `start-build` builds a mesh and writes it. `kofl commands` prints this catalogue as JSON (`koflcraft.tool-catalogue`) with the full schemas; `kofl call <id> --input file.json` runs a tool and prints the result envelope (`koflcraft.tool-result`). Configurations are given inline in the input, files by path.

## Diagnostic codes

| Code | Name | Severity | Meaning | Fix |
|---|---|---|---|---|
| `TOOL001` | `unknown_tool` | error | No tool has this id. | Run `kofl commands` for the ids. |
| `TOOL002` | `invalid_arguments` | error | The input does not match the tool's input schema. | Compare the input with the schema in `kofl commands`. |
| `TOOL003` | `journal_failed` | warning | The journal could not be written: the call ran, but the journal misses it. | Check that the journal path is writable. |
| `TOOL004` | `invalid_script` | error | A replay script is not JSON lines of journal calls, or has no calls. |  |
| `TOOL005` | `replay_differs` | error | A replayed call ended differently from its record (status, exit code or result digest). |  |
| `TOOL006` | `invalid_path` | error | A path is outside the read or write roots, or not a plain file name where one is needed. | Use a path inside the roots given to `kofl mcp`. |
| `TOOL007` | `usage` | error | The command line is not one of the documented forms. | Run `kofl --help`. |
| `TOOL008` | `limit_exceeded` | error | The input exceeds a limit of this front end (sites, facets, layers, cells, file size). | Run the tool from the command line, which has no limits, or reduce the input. |
| `TOOL009` | `approval_required` | error | The build needs approval under the MCP policy (`ask`), but the MCP client cannot ask (it has no elicitation capability). | Use an MCP client with elicitation, set the rule to `allow` in the policy file, or run the build from the command line. |
